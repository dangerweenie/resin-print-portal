General

Leave unchecked in almost all cases — even printers that technically read into subfolders don't display the folder names on screen, so attribution is only visible when files are flattened with the member's name in the filename. Confirmed: Anycubic M7 Pro / P1 recurse into subfolders (files aren't lost) but never show folder names on screen. Elegoo Saturn 3 is root-only — subfolder files don't appear at all. Saturn 4 is unconfirmed, assumed root-only for now. When unchecked, the USB sync flattens every member's files to the drive root with their name prefixed onto the filename.
